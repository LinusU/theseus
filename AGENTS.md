# Theseus

See README.md and doc/development.md for the project overview.

## Populous: The Beginning port (branch `lu-poptb`)

Goal: run `poptb.exe` (Populous: The Beginning 1.02, GOG) natively on
macOS through Theseus — no x86, Windows, or DOS execution.

### Layout

- `poptb-input/` — GOG installer (ignored; copy to each machine manually)
- `scratch/poptb/install/` — extracted game files: `poptb.exe`, `qmixer.dll`,
  `weanetr.dll`, plus `d3dpoptb.exe`/`poptbuw.exe`/`dxcfg.exe` (ignored)
- `out/poptb/` — checked-in generated crate skeleton; `src/generated/` is
  regenerated by tc and ignored

### Build and run

```bash
out/poptb/translate.sh                       # runs tc on poptb.exe
cargo build --profile fast -p poptb
out/poptb/run.sh                             # runs from scratch/poptb/install
```

Environment toggles:

- `THESEUS_DUMP_FRAMES=1` — write presented frames as `frame_N.ppm` in cwd
- `RUST_LOG=info` — winapi logging (DirectDraw calls log `eip_context`)

`host/src/sdl.rs` injects an Escape keypress after ~5 s of event idle so
unattended runs skip the intro.

### Status

Working:

- DirectDraw init, primary surface, back buffer, system-memory offscreens
- 8bpp palettized and 16bpp pixel-format queries (`GetPixelFormat` returns
  nonzero masks/FourCC because callers bit-scan them)
- `Flip` and SDL presentation; frame dumps render

Current blocker:

- Startup crashes with `jmp to unknown addr 0x0000006c` after `Flip`.
  `Context::recent`/`recent_eip` (runtime/src/machine.rs) points at generated
  fns near `x55c2b0`/`x55c2cd`/`x55c307`/`x55c333` (out/poptb/src/generated/
  part_39.rs), which do COM-ish indirect calls reading `[ecx+0x60]` and
  `[ecx+0x6c]`.
- The panic dumps candidate objects: `0x006643e0` (vtable `0x04fd5dc8`),
  `0x009b607a`, `0x114c`, `0x160`. `0x6c` looks like a method offset being
  treated as a function address — suspect a wrong interface/vtable mapping
  or an unmodeled D3D object rather than a missing entry point.
- Note: `eip_context` is stale at `ctx.indirect32(addr)` call sites because
  the target is evaluated before `call32` updates it; `recent_eip` is the
  more reliable trail.

Not yet verified: gameplay, sound/music (qmixer/weanetr are stubbed),
clean exit.
